Android Kernel

基于 Linux Kernel 的 Android 系统内核

推荐学习路线

阶段一：Linux 基础

先掌握 Linux 内核基本概念：进程管理、内存管理、文件系统、系统调用。阅读《Linux Kernel Development》或《Understanding the Linux Kernel》。

阶段二：内核编译与调试

搭建 AOSP 编译环境，学习内核配置（defconfig）、交叉编译、刷机。掌握 printk、ftrace、crash 等调试工具。

阶段三：Android 特有子系统

深入 Binder IPC、Ashmem、ION/DMA-BUF、Android GKI 架构、SELinux 安全策略、init/property 系统。

阶段四：驱动与硬件抽象

学习 Linux 设备驱动模型，实践编写字符/块/网络设备驱动。理解 DTS、HAL 与内核交互、SoC 外设驱动开发。

阶段五：性能与功耗优化

掌握 CPU 调度（EAS/WALT）、thermal 管理、suspend/resume 流程、wakelock 机制、内存压缩（ZRAM/KSM）。

阶段六：安全与上游贡献

深入理解 Android 安全模型、CVE 分析、GKI 模块化。尝试向 AOSP 或上游 Linux 社区提交 patch。
