系统应用开发学习路线

阶段一：系统应用基础与构建

理解 platform 签名、privileged 权限、LOCAL_CERTIFICATE / android:sharedUserId 配置。搭建 AOSP 编译环境，掌握 packages/apps 下的模块构建 (Android.bp / Android.mk)。学习 @hide API 的使用方式 (反射 / 编译时引用 / bootclasspath)。

阶段二：系统设置与 Preference 框架

以 Settings 应用为切入点，理解 AOSP Settings 的目录结构、DashboardFragment / SettingsPreferenceFragment 体系。学习 Preference 层次化组织、搜索索引 (SearchIndexablesProvider)、子页面动态注册。

阶段三：SystemUI 与通知系统

深入 SystemUI 源码，理解 StatusBar / NotificationPanel / QuickSettings / LockScreen 的架构。学习 NotificationChannel、通知分发流程、自定义 QS Tile、状态栏图标管理。

阶段四：Launcher 与桌面定制

阅读 Launcher3 源码，理解 InvariantDeviceProfile、CellLayout、DragLayer、Workspace 的工作原理。学习 AppWidget 管理、应用抽屉实现、拖拽排序、手势导航集成。

阶段五：多用户、企业管控与安全

理解 UserManager 多用户管理、DevicePolicyManager 企业管控、Work Profile 工作资料。学习设备管理员 (Device Admin) 配置、应用限制策略、跨用户 IPC 通信。

阶段六：系统集成与发布

学习系统应用的预装配置 (PRODUCT_PACKAGES)、Overlay 资源覆盖 (RRO)、OTA 升级集成。掌握 CTS / VTS 合规测试、平台签名密钥管理、发布流程与版本管理。
