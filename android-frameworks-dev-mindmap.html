高级 Frameworks 开发学习路线

阶段一：AOSP 编译环境与源码结构

搭建完整 AOSP 编译环境 (Ubuntu / 高性能服务器)，理解 repo 工具、Android.bp / Android.mk 构建系统。通读 frameworks/base、frameworks/native、system/core 的目录结构，理解 Framework 层代码组织方式。

阶段二：系统启动全流程

深入分析 init 进程启动、init.rc 解析、属性服务、Zygote 启动与预加载机制、SystemServer 启动流程 (startBootstrapServices → startCoreServices → startOtherServices)。理解每个阶段的服务初始化顺序与依赖关系。

阶段三：Binder IPC 全链路

从内核驱动 ioctl 开始，理解 ServiceManager 注册/查询、Proxy/Stub 模式、AIDL 编译生成代码、HwBinder / Binder3 的演进。实践自定义系统服务并完成 AIDL 接口定义、服务注册、客户端调用全流程。

阶段四：核心系统服务源码阅读

选择一个核心服务 (推荐从 PMS 或 WMS 入手) 进行源码级阅读。理解服务的启动初始化、请求处理流程、锁机制、与其他服务的交互。使用 GDB/LLDB 进行断点调试，结合 logcat 和 dumpsys 验证理解。

阶段五：图形与显示管线

理解 Surface / SurfaceControl / SurfaceFlinger 的关系，学习 BufferQueue 生产者-消费者模型、HWC HAL 合成策略、HWUI 渲染管线 (DisplayList → RenderThread → GPU)。掌握 Systrace/Perfetto 分析 Jank 的方法论。

阶段六：Framework 定制与贡献

尝试修改 Framework 层代码实现自定义功能 (如新增系统服务、修改窗口行为、扩展权限模型)。学习 Gerrit 代码审查流程，尝试向 AOSP 提交 patch。研究 Treble 架构下的 HAL 开发与 APEX 模块化。
